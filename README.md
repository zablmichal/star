# Starbie

A star-shaped desk pet built around a Seeed Studio XIAO ESP32 board. A tiny pet wanders across a 0.96" OLED, reacts to being tilted or shaken (MPU6050), and can read the temperature and humidity of its surroundings (DHT11). Two Cherry MX switches open a radial menu and a stats screen.
