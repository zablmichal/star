# Starbie

Starbie is a small handheld-style desk pet built on a Seeed Studio XIAO ESP32 board. A tiny pixel pet wanders across a 0.96" OLED screen. You control it with two buttons and by tilting or shaking the board. An on-board DHT11 sensor can also read the temperature and humidity around it.This project is based on the Starbie Week 1 guide from the Half-Life project. What I added is a custom star-shaped PCB, its own silkscreen artwork, and the documentation and manufacturing files in this repository.I build it that i made layout in schematic editor and then move on to pcb editor and i made custom shape PCB. Put all parts on the PCB and wired everithing. I acually wired it wrong for the firs time but i fixed it and my pcb was cutted out wrong too but i fixed that one too.
